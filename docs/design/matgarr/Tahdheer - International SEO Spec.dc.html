Blocking dependency — read before scheduling any of this

§273 instructs an inspection first. It returned: no multilingual plugin (no WPML / Polylang / TranslatePress), no locale routing, and no language switcher anywhere in the theme. inc/setup.php:16 loads a textdomain and inc/woocommerce.php:63 filters account-menu labels — that is the whole of the current localisation. §21–§24 forbid inventing URL architecture and require crawlable locale URLs, so hreflang cannot legitimately be emitted at all yet: there is nothing to point it at. Every locale-URL-dependent item below is therefore gated on one decision — install a multilingual plugin, or build in-theme locale routing. Nothing in §25–§35 can ship before it.
